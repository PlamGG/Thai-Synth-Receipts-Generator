**Thai-Synth-Receipts-Generator** is a robust, highly realistic procedural generation engine for creating synthetic Thai commercial documents. It is specifically designed to generate large-scale, pixel-perfect datasets for training and evaluating state-of-the-art Document AI and Optical Character Recognition (OCR) models (e.g., Donut, LayoutLMv3, TrOCR).

🔗 **Pre-generated Dataset:** If you are looking for the ready-to-use 15,000 images dataset generated by this engine, please visit our [Hugging Face](https://huggingface.co/datasets/DuckerMaster/Thai-Synth-Receipts) or Kaggle repository.

---

## 🚀 Core Features

### 1. Advanced Layout Engine (6 Templates)
The engine renders text, tables, and logos using absolute coordinates and dynamic text wrapping.
- Formal B2B Tax Invoices (Grid-based tables)
- Retail Supermarket Receipts
- Minimalist Cafe Thermal Slips
- Handwritten Cash Receipts (Simulating human handwriting with script fonts)
- Quotations and Purchase Orders

### 2. Built-in Bounding Box Annotation
As the engine draws text onto the canvas, it simultaneously calculates precise polygon coordinates `[[x1,y1], [x2,y1], [x2,y2], [x1,y2]]`. The output is saved directly into a Hugging Face compatible `metadata.jsonl` format, removing the need for manual OCR labeling.

### 3. Realistic Image Augmentations (3 Variants)
To train robust models that work "in-the-wild", the engine applies complex OpenCV transformations:
- **`clean`:** Perfect digital baseline.
- **`error`:** Simulates printer/scanner defects (faded ink, vertical streaks, folded paper, ghosting, ink blobs).
- **`photo`:** Simulates smartphone camera captures (motion blur, glare, fluorescent/tungsten lighting tints, non-linear gamma distortion, perspective warping).

### 4. Zero-Shot Split Strategy
The generation pipeline enforces a strict physical separation of entities between data splits. Fictional merchants, customers, and items assigned to the `validation` and `test` splits are guaranteed to be 100% unseen in the `train` split.

## ⚙️ Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/PlamGG/Thai-Synth-Receipts-Generator.git
   cd Thai-Synth-Receipts-Generator
   ```

2. **Create a virtual environment and install dependencies:**
   ```bash
   python -m venv .venv
   
   # Activate the environment (Windows)
   .venv\Scripts\activate
   
   # Install requirements
   pip install Pillow opencv-python numpy pyyaml python-dotenv huggingface_hub
   ```

3. **Environment Setup:**
   Copy `.env.example` to `.env` and add your API keys if you intend to use the LLM-based catalog generator script:
   ```bash
   cp .env.example .env
   ```

## 🛠️ Usage

### 1. Configuration
Adjust the generation parameters in `config.yaml`:
```yaml
dataset:
  num_samples_per_type: 312  # Total documents per type
  splits:
    train: 0.8
    validation: 0.1
    test: 0.1
```

### 2. Generate the Dataset
Run the main pipeline. The engine will read the catalogs, render the images, apply augmentations, and save the outputs to the `dataset/` directory.
```bash
python generate_v3.py
```

## 🛡️ Privacy & Compliance
All text entities (names, addresses, tax IDs, phone numbers) inside `catalog_large.json` and `catalog_unseen.json` are **100% fictional and procedurally generated**. There is no Personally Identifiable Information (PII) involved in this project.
